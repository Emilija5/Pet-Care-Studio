# Pet Care Studio

Групен проект по предметот Деловна пракса 2025/2026.

Pet Care Studio е презентациска веб-страница за салон за нега на кучиња и мачки.

## Членови

- **Емилија Антовска** — почетна страница, визуелен дизајн и тестирање
- **Аника Панова** — услуги и ценовник
- **Матеа Илиева** — тим, блог и содржина
- **Ангела Младеновска** — контакт-форма и cookies

## Страници

- Почетна
- Услуги и ценовник
- Тим
- Блог
- Контакт

Сите страници се достапни на македонски и англиски јазик.

## Функционалности

- Responsive навигациско мени
- Филтрирање на услугите
- FAQ секција
- Прикажување дополнителни блог-објави
- Контакт-форма со JavaScript валидација
- Избор и запомнување на cookie preference
- Македонска и англиска верзија

## Технологии

- HTML5
- CSS3
- JavaScript
